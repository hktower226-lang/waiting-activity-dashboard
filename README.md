# 경기지역본부 대기자 활동 현황판

기존 제공된 HTML + JSON 기반의 정적 웹사이트입니다. `index.html`과 `data.json`은 같은 경로에 있어야 합니다.

## 용도 및 공개 범위

- 카카오톡 오픈채팅 공지에 웹 주소를 고정하여 누구나 로그인 없이 열람할 수 있도록 합니다.
- 이 저장소는 **Public**으로 만들고 GitHub Pages를 활성화해야 합니다.
- Public 공개 시 검색엔진 차단 설정이 있더라도 사이트 내용(실명·활동 내역)은 사실상 누구나 접근 가능한 정보입니다. 활동자 정보 공개 범위 확인 후 게시하세요.
- 대체업무 내역은 이 대시보드에 포함하지 않습니다. 다른 프로젝트 대화방에서 관리합니다. 단, 원본 활동기록 속 '대체근무' 언급은 기록 보존을 위해 원문대로 남겼습니다.

## 새 저장소 배포

1. https://github.com/new 에서 `waiting-activity-dashboard` 이름으로 **Public** 저장소를 생성합니다. 기존 `chunsung`, `chunsung1`은 사용하지 않습니다.
2. 이 폴더의 `index.html`, `data.json`, `robots.txt`, `README.md`를 새 저장소 루트에 올립니다. 또는 새 저장소 주소를 ChatGPT 대화방에 알려 파일 업로드를 요청할 수 있습니다.
3. GitHub 저장소의 **Settings → Pages**에서 **Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
4. GitHub Pages에서 실제 게시 주소가 표시되고 열린 것을 확인한 다음 카카오톡 오픈채팅 공지에 링크를 고정합니다.

## 이후 업데이트 규칙

사용자가 이 대화방에 활동내역을 텍스트로 보내며 '대기활동 현황판 업데이트'를 요청하면:

1. 기존 GitHub `data.json`을 먼저 읽고 본문에서 날짜·지부·성명·활동내용·시간을 추출합니다.
2. 동일 날짜, 지부, 성명, 활동내용, 시간의 **완전 동일 중복**은 추가하지 않습니다. 같은 날 별도 1차/2차 활동처럼 내용이 다른 기록은 유지합니다.
3. 신규 기록만 `D[YYYY-MM-DD]`에 누적합니다. 기존 `SD`, `R`, `BC`, 과거 이력은 유지합니다. 명단 추가/보류/시작일 변경은 사용자가 명시적으로 알려줄 때만 합니다.
4. 애매한 성명·지부·날짜는 임의로 채우지 않고 확인대상으로 알립니다.
5. 데이터 검증 후 연결된 GitHub 새 저장소의 `main:data.json`을 갱신 커밋합니다.
6. 웹페이지를 새로 열면 갱신된 데이터를 읽습니다. 별도 자동 크롤링/백그라운드 동기화 기능은 없습니다.

## 통계 원칙

- 일일 보고 인원/지부별 보고 인원: **날짜별 이름 중복 제거**.
- 개인별 누적 활동 횟수: 제공된 `SD` 기본값 + 활동 원본 기록의 각 건(명시적 복수 활동은 별도 건).
- 대기자 총원: `R`의 인원. 기록에만 존재하고 `R`에 없는 이름은 자동으로 명단에 편입하지 않습니다.
- 기간 만료는 `R` 시작일에서 4개월을 더한 날짜 기준으로 브라우저에서 계산하며, 보류 표시는 `R`의 네 번째 값 기준입니다.

## 이번 데이터 확인 사항

- 제공 자료 기준: 대기자 명단 44명, 날짜 51일, 활동 기록 240건.
- 최근 활동일: 2026-10-16.
- `김정현` 이름은 활동 기록에 등장하지만 `R`(대기자 명단)에는 없습니다. 명단 편입 여부는 확인이 필요하며, 자료는 원형 그대로 보존했습니다.
